# java-calculator-precourse

## 프로그램

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

## 기능

1. 입력 
    - [X]  사용자로부터 문자열을 입력 받는다.
    - [ ]  입력이 비어있는 경우 0을 반환한다.
    - [ ]  `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.
2. 문자열 파싱
    - [ ]  커스텀 구분자가 지정된 경우(`"//<구분자>\n"`) 해당 구분자를 추출한다.
    - [ ]  커스텀 구분자 포함 구분자로 문자열에서 숫자 부분만 추출한다.
3. 숫자 변환 및 계산
    - [ ]  분리된 문자열을 정수로 변환한다.
    - [ ]  `IllegalArgumentException`을 발생시킨다.
    - [ ]  숫자가 아닌 값이 포함된 경우 예외를 발생시킨다.
    - [ ]  추출한 숫자들의 합을 계산한다.
4. 출력
    - [X]  `"결과 : <합계>"` 형식으로 결과를 출력한다.

### 예외처리

- [ ]  입력이 **`null`**이거나 공백 문자열인 경우 0을 반환한다.
- [ ]  음수 입력 또는 숫자가 아닌 값을 포함한 경우 **`IllegalArgumentException`** 발생시키고 프로그램을 종료 시킨다.
- [ ]  숫자, 기본 구분자, 등록된 커스텀 구분자 외 문자를 입력한 경우 **`IllegalArgumentException`** 발생시키고 프로그램을 종료 시킨다.
